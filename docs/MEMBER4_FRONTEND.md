# Member 4 guide — Frontend ↔ blockchain

Everything the UI needs comes from `integration/machinapay.contracts.json` (generated by Member 1's deploy):
`{ network, chainId, rpcUrl, explorerUrl, nativeToken, addresses:{MachineRegistry, JobEscrow}, verifier, eip712, abi:{MachineRegistry, JobEscrow} }`.
Import it (Vite: `import cfg from "./machinapay.contracts.json"`). Use **ethers v6**. The frontend must read **real chain state** — never keep a fake local job state.

## 1. Connect MetaMask + switch to MST testnet
```ts
import { BrowserProvider, Contract, JsonRpcProvider, parseEther, formatEther,
         encodeBytes32String, decodeBytes32String, keccak256, toUtf8Bytes } from "ethers";

export async function connect() {
  const eth = (window as any).ethereum;
  await eth.request({ method: "eth_requestAccounts" });
  try {
    await eth.request({ method: "wallet_switchEthereumChain", params: [{ chainId: "0x5752035" }] });
  } catch {
    await eth.request({ method: "wallet_addEthereumChain", params: [{
      chainId: "0x5752035", chainName: "MST Testnet",
      rpcUrls: ["https://testnetrpc.mstblockchain.com"],
      nativeCurrency: { name: "MSTC", symbol: "tMSTC", decimals: 18 },   // confirm symbol in the faucet/MetaMask
      blockExplorerUrls: ["https://testnet.mstscan.com"],
    }]});
  }
  const provider = new BrowserProvider(eth);
  const signer = await provider.getSigner();
  return { provider, signer, address: await signer.getAddress() };
}
```
For **read-only** views (machine dashboard, job list, feed) use a `JsonRpcProvider(cfg.rpcUrl, cfg.chainId, { cacheTimeout: -1, staticNetwork: true })` so it works without a wallet.
Chain id `91562037` = `0x5752035`.

## 4. Create job (customer locks 100)
```ts
const description = "Move package A to green zone";
const jobId = keccak256(toUtf8Bytes(crypto.randomUUID()));      // new random id per job
const tx = await escrowW.createJob(
  jobId, keccak256(toUtf8Bytes(description)), 3600 /* seconds until expiry */, description,
  { value: parseEther("100") }                                   // <- THIS is the locked reward
);
const receipt = await tx.wait();
explorerLink = `${cfg.explorerUrl}/tx/${tx.hash}`;
```
Save `{ jobId, description }` in your backend/state — the chain stores only `metadataHash`; the text is in the `JobCreated` event (`description`).
The customer wallet needs ≥ reward + gas. If the faucet gives less than 100, use a smaller reward for rehearsal.

## 5. Read a job and render status
```ts
const STATE = ["CREATED","FUNDED","ACCEPTED","EXECUTING","PROOF_SUBMITTED","VERIFIED","PAID","REFUNDED"];
if (await escrow.jobExists(jobId)) {
  const j = await escrow.getJob(jobId);
  const state = Number(j.state), verdict = Number(j.verdict);   // verdict: 0 none, 1 pass, 2 fail
  // j.customer, j.machineId (bytes32; 0x00..00 until accepted), j.machineWallet, formatEther(j.reward),
  // j.deadline (unix s), j.proofHash, j.evidenceHash
}
```
**UI mapping** (a FAIL verdict does *not* change `state`):
| state / verdict | Show |
|---|---|
| 1 | Funded – waiting for machine |
| 2 | Accepted |
| 3 | Executing (robot running) |
| 4 & verdict 0 | Proof submitted – verifying |
| 4 & verdict 2 | **Rejected by verifier – refund pending** |
| 5 | Verified – releasing payment |
| 6 | **Paid** |
| 7 | **Refunded** |

List jobs: `const ids = await escrow.getJobIds(0, 50)` (pagination) and `await escrow.jobCount()`. Escrow balance shown in UI: `await escrow.totalLocked()` (equals the contract's real balance).

## 6. Customer actions from the UI
```ts
await (await escrowW.refund(jobId)).wait();   // cancel an unaccepted job, or claim refund after FAIL / expiry
```
`refund` reverts with `NotRefundable` if conditions aren't met. Accept/start/proof/attestation/release are done by Member 3's services, not the browser.

## 7. Live event feed
```ts
// history for the feed
const latest = await readProvider.getBlockNumber();
const logs = await escrow.queryFilter("*", latest - 5000, latest);        // add registry events the same way
logs.forEach(l => { const name = (l as any).fragment?.name; /* JobCreated, JobAccepted, ... */ });

// live
for (const ev of ["JobCreated","JobAccepted","JobExecutionStarted","ProofSubmitted",
                  "VerificationSubmitted","JobVerified","PaymentReleased","JobRefunded"])
  escrow.on(ev, (...args) => pushToFeed(ev, args));

// filter by indexed fields (all of a customer's jobs / one job's timeline)
await escrow.queryFilter(escrow.filters.JobCreated(undefined, customerAddress));
await escrow.queryFilter(escrow.filters.PaymentReleased(jobId));
```
If a public RPC doesn't support `eth_getLogs` over wide ranges, keep ranges small (≤ 5000 blocks) or poll every few seconds. For chains with WebSocket use `new WebSocketProvider("wss://testnetrpc.mstblockchain.com")` for push events.
Every transaction hash → link `${cfg.explorerUrl}/tx/${hash}` (addresses: `/address/${addr}`).

## 8. Error messages
```ts
try { … } catch (e: any) {
  const err = escrow.interface.parseError(e.data ?? e.info?.error?.data);
  showToast(err?.name ?? e.shortMessage);   // e.g. ZeroReward, JobExpired, NotRefundable
}
```
User rejecting in MetaMask throws `ACTION_REJECTED` — don't treat as failure.
